# 企业入驻页面

入口：`/enterprise/apply`。H5 与电脑 Web 共用此 URL、同一套组件及接口，按屏幕宽度调整布局。官网独立公开申请页，采用品牌页头与居中表单，不使用企业管理侧栏或管理平台框架。独立申请，不创建买家会员、不使用旧会员认证。

三步：企业与联系人资料 → 营业执照 → 短信验证与申请确认。行业、规模读取 wx-backend 新入驻接口。当前支持中国大陆企业和大陆手机号，英文界面不代表开放海外主体申请。

公开申请接口：`/api/enterprise/applications`，由网站服务端转发 `/api/v1/web/enterprise-applications`。字典、短信及营业执照上传分别使用 options、sms 和已有上传路由。所有写入经过来源校验、体积限制和后端校验。浏览器不能指定权限字段、短信场景或任意后端路径。

草稿仅主动保存时写入当前浏览器。保存文本及已上传文件信息，不保存验证码、同意状态或请求编号。提交成功清理草稿。失败重试复用同一资料的请求编号，避免重复申请。

申请成功展示申请编号和真实状态。审批由运营端完成并创建企业账号；本期没有公开查询、邮件通知和申请后自动登录，页面不展示这些入口或承诺。

## 联调及发布

2026-10-01 dev 数据库已迁移并核验。生产未迁移。本地启动后端4000和网站3000可读取真实 dev 选项。浏览器流程测试模拟短信、上传和提交，不发送真实验证码、不写测试企业申请。

网关部署需核验访客 IP 的可信传递，否则后端会把所有访客识别成网站服务器，共享每小时20次申请限额：

1. 网站入口网关覆盖 `X-Real-IP` 为真实客户端地址，阻止绕过网关直接访问 Next。网站设置 `TRUST_PROXY=true`。
2. Next 只转发经单一 IPv4/IPv6 校验的 `X-Real-IP`，默认不转发。后端设置 `WEB_ENTERPRISE_TRUST_PROXY=true`。
3. API 网关仅对可信网站服务器来源保留此头；其他来源必须覆盖为真实来源地址。不能无条件信任客户端提交的头，也不能对可信网站请求再次改写成网站服务器 IP。
4. 开发和生产各自验证两名访客独立限流；同时保留后端每手机号5次/小时限制。网关设置未核验前不能宣称线上多人联调完成。

类型检查、lint、单元测试、隔离构建与桌面/手机浏览器验证在 next-web 执行。真实短信、OSS上传及运营审批的外部联调仍需部署后核验。

## 小程序轮播图入口

现有 my-miniprogram 的 `jumpType=h5` 会将 `h5Url` 编码传入 `/pages/common/webview/index?url=...`，再由 Taro WebView 打开。无需另建小程序原生入驻表单。

轮播图的 H5 地址填写 `https://实际网站域名/enterprise/apply?entry=miniapp`。这里是网站域名，不是 wx-backend 的 API 域名。此参数仅调整展示：品牌页头保留但不链接官网，隐藏返回网站首页；小程序使用原生返回控制退出。普通浏览器直接访问 `/enterprise/apply` 仍展示完整网页导航。表单、草稿、验证码与接口完全共用。

小程序身份或登录 token 不通过 URL 传递；当前为独立公开申请，联系人仍需要短信验证。提交成功显示申请编号，不自动创建小程序会员。网站尚未部署时本地 localhost 不能作为轮播图正式地址。上线需核验 HTTPS、微信业务域名、营业执照选择/上传与小程序真机 web-view 行为；模拟浏览器测试不替代真机验证。
