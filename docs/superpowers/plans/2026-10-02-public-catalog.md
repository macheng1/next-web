# 官网四页实现计划

**目标**：按已确认 V2 设计依次实现首页、产品目录、产品详情、企业主页。
**技术**：Next App Router、React、Tailwind、Semi UI；wx-backend 公开只读接口。
**设计**：工作区 output/web-design-v2/01-public-language-dropdown-v3.png。

## 约束
- 复用语言、请求、状态、元信息、Semi 包装组件。
- 企业上架且产品未下架、未被平台限制才可公开；不返回账号、电话、执照及监管字段。
- 不编造产品、翻译、能力或认证；缺少数据展示空状态。
- 企业入驻沿用现有独立页面；未完成的登录、询盘、工具不做可点击入口。
- 当前完成本地代码和验证，不提交、推送或部署。

## 实施顺序
- [x] 新增后端 web/catalog 产品列表/详情、企业列表/详情、筛选选项；参数验证与可见性测试，无数据库迁移。
- [x] 公共模型和 BFF、共享导航/语言下拉/图片/搜索/卡片/分页/错误状态。
- [x] 首页：工业主视觉、双搜索、行业入口、真实产品展示。
- [x] 目录：URL 驱动搜索、分类/行业筛选、排序、分页；手机筛选面板。
- [x] 详情：图库、键值参数、规格与参考价、供应商入口。
- [x] 企业主页：公开资料、产品、相册、公司资料切换。
- [x] 单元、桌面/手机浏览器、中英文、无结果、错误、404、键盘；前后端构建和 lint。

## 审查重点
下架和软删产品不得泄露；异步搜索不能覆盖新结果；翻页/筛选保留语义；长名称与窄屏不溢出；图片失败和缺少规格正常降级。
